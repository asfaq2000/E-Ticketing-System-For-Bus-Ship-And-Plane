🚌🛳✈️ E-Ticketing System (Java Swing)

This project is a Java-based E-Ticketing System built with Java Swing for the GUI. It supports online booking and ticket management for Bus, Ship, and Plane travel. The application provides a user-friendly interface for selecting routes, choosing travel modes, booking tickets, and viewing booking history.

🔧 Features

* Multi-modal ticketing (Bus, Ship, Plane)
* Graphical user interface using Java Swing
* Route and schedule selection
* Passenger data input and ticket confirmation
* Booking history and ticket management
* Basic validations and error handling

🛠 Technologies Used

* Java
* Java Swing (GUI)
* File handling or database integration (depending on version)
* Object-oriented programming

📦 How to Run

1. Clone the repository
2. Open the project in any Java IDE (e.g., IntelliJ, Eclipse, NetBeans, VS Code)
3. Compile and run the main class (e.g., start.java)
4. Use the GUI to start booking tickets
